# 🛍️ E-Commerce Sales Analysis

An end-to-end **E-Commerce Sales Analysis** project that uses SQL and Python to explore sales data, identify trends, understand customer purchasing patterns, and uncover product and category performance.

The project combines **MySQL/SQL for data querying** with **Python-based exploratory data analysis and visualization** to transform raw sales data into meaningful business insights.

## 📌 Project Overview

Understanding sales data is essential for identifying what products perform well, how sales change over time, and where opportunities for growth exist.

This project analyzes an e-commerce dataset to answer questions such as:

- 📦 Which products generate the highest sales?
- 🏷️ Which categories perform best?
- 📈 How do sales change month by month?
- 👥 What patterns can be observed in customer purchases?
- 🌎 How does sales performance vary across different regions?
- 💰 What factors contribute to overall sales performance?

The analysis includes data cleaning, exploratory data analysis, statistical analysis, SQL queries, and data visualization.
